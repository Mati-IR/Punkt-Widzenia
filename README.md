# Punkt Widzenia

Static site (Astro) mapping Polish news outlets.

## Start

Requires Node.js 22.

```sh
npm install
npm run dev      # http://localhost:4321
```

## Other commands

```sh
npm run build    # type-check + build to dist/
npm run preview  # serve the built site
```

Data lives in `data/`. More in `docs/`.
